## API database configuration

- Copy SetEnv.sample.cmd and rename it to SetEnv.cmd
- Enter your secrets, environment should stay as Development except when neccessary for prod tests
- Navigate to /Pixelmon.Api in a terminal or shell
- Run `./setenv.cmd`
- You can now run the API with `dotnet run`
